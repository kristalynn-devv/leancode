# HANDOFF.md template

```markdown
# HANDOFF
updated: <timestamp>

<one line>

## Steps
- [x] 1. ...
- [ ] 2. ...   <- current

## State
branch: <branch>   last commit: <sha>
uncommitted: <files>

## Decisions
- chose X over Y because ...

## Next action
<the exact command or edit to do next>

## Blockers
- <if any>
```
